# Codex Instructions

## Generated mocks

Files inside `internal/mocks/` are generated by Mockery.

Do not inspect or analyze the full contents of generated mock files.

When writing tests, you may use mocks only by their public constructors and methods, for example:

- `mocks.NewReservaStore(t)`
- `mocks.NewClienteStore(t)`
- `mockStore.EXPECT().Method(...)`

To understand available methods and contracts, read the original interfaces in:

- `internal/*/model.go`

Only open files in `internal/mocks/` when strictly necessary to confirm the generated constructor or method name. If you need to inspect them, read only the relevant symbol, not the whole file.

When mocks need to be updated, edit only:

- `.mockery.yml`

Then regenerate mocks with:

```bash
mockery
